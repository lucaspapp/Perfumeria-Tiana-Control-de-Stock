Acerca de Perfumería Tiana

El comercio

Perfumería Tiana es un comercio dedicado a la venta de perfumes, cosméticos, productos de higiene personal y artículos de cuidado diario.

Este sistema permite consultar el inventario y mantener un registro ordenado de los productos que ingresan y salen del comercio.

Objetivo del sistema

El objetivo es conocer en todo momento qué productos existen, cuántas unidades hay disponibles y cómo se mueve la mercadería.

La información se guarda mediante una API PHP conectada a una base de datos MySQL o MariaDB.

Forma de ingreso de datos

1. Registrar producto

Se ingresa un código único, por ejemplo P001, y el nombre del producto. El producto comienza con existencia cero.

2. Registrar entrada

Se selecciona el producto, se informa el precio de compra, la cantidad ingresada y una observación. La cantidad aumenta el stock.

3. Registrar salida

Se selecciona venta o pérdida, se informa la cantidad y los datos correspondientes. El sistema verifica que exista stock suficiente.

Las ventas registran un precio de venta y las pérdidas representan productos que salen sin generar ingresos. Cada movimiento actualiza automáticamente las existencias y queda disponible en el historial.
